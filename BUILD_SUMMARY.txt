================================================================================
                      🏃 HOW TO RUN THE APP
================================================================================

Prerequisites
   1. Node.js v14+ and npm installed
   2. Expo CLI: npm install -g expo-cli
   3. Android emulator or device
   4. Backend API running (at http://10.111.4.25:3000/api)

Setup
   1. cd /home/henrymaina/Desktop/budget-app/mobile/Budget-App
   2. npm install (if first time)
   3. Update API_BASE_URL in src/config/api.js if needed

Running
   Option 1 - Interactive menu:
      npm start

   Option 2 - Direct to Android:
      npm run android

   Option 3 - Direct to iOS:
      npm run ios

   Option 4 - Web preview:
      npm run web

Testing
   • Scan QR code with Expo Go app (on real device)
   • Use Android/iOS emulator
   • Test all navigation tabs
   • Add sample transactions
   • Check analytics and charts
   • Test pull-to-refresh
   • Verify logout flow
